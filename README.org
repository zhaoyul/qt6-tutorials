* Qt6 系统学习项目

本仓库按统一章节组织 Qt6 教程示例，主线为 C++，同时提供 Python
(PySide6)、Basilisp 和 Clojure 版本，方便对照同一主题在不同语言里的写法。

** 先读这个

- 章节编号是主索引: =01_core= 到 =12_project= 按学习顺序递进。
- =book/= 是教材文本，=cpp/=、=python/=、=basilisp/=、=clojure/= 是可运行示例。
- C++ 版本是最完整的构建基线；其他语言尽量保持同章对应，但会有少量额外示例。
- =08_multimedia= 和 =11_3d= 依赖可选 Qt 模块；没有安装对应模块时，不必先解决这些章节。

** 环境要求

| 目录         | 必需工具                          | 说明 |
|--------------+-----------------------------------+------|
| =cpp/=         | Qt 6.5+, CMake 3.16+, C++17 编译器 | 使用 CMake 构建；推荐 Qt 6.6+ |
| =python/=      | Python 3.9+, PySide6 6.5+          | 推荐先建 venv 再安装 =requirements.txt= |
| =basilisp/=    | Python 3.9+, PySide6, Basilisp     | 运行入口是 =python -m basilisp.cli run ...= |
| =clojure/=     | Clojure CLI, JDK 17+, Python 3.9+, PySide6 | =clj= 运行时必须能找到装有 PySide6 的 Python |
| 可选章节     | Qt Multimedia, Qt 3D              | 只影响 =08_multimedia/= 和 =11_3d/= |

** 5 分钟上手

如果你只是想先确认环境, 从 C++ 版本开始; 如果你想快速改界面效果, 从
Python 版本开始; 如果你要对照 Lisp 风格绑定, 再进入 Basilisp 或 Clojure。

*** C++ 版本

#+begin_src bash
cmake -S cpp -B cpp/build
cmake --build cpp/build --target meta_object_demo -j 8
./cpp/build/01_core/01_meta_object/meta_object_demo
#+end_src

如果 =cmake= 找不到 Qt:

#+begin_src bash
cmake -S cpp -B cpp/build \
  -DCMAKE_PREFIX_PATH=/path/to/Qt/6.x.x
#+end_src

*** Python 版本

#+begin_src bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r python/requirements.txt
python python/01_core/01_meta_object/main.py
#+end_src

*** Basilisp 版本

#+begin_src bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pyside6 basilisp
python -m basilisp.cli run basilisp/01_core/01_meta_object/main.lpy
#+end_src

*** Clojure 版本

先确保当前 shell 中的 Python 能直接导入 =PySide6=，再运行 Clojure alias:

#+begin_src bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install PySide6
cd clojure
clj -M:ch01-core-meta-object
#+end_src

** 各语言目录差异

- Python 和 Basilisp 的 =05_quick/= 目录额外包含 =01_animations/= 预热示例。
- Clojure 通过 =src/qt6_tutorials/...= 提供可运行命名空间，并在 =deps.edn= 中为每个示例定义 alias。
- Clojure 额外提供 =13_reagent/=，用于数据驱动 UI 的实验性示例。

** 运行约定

- C++: 构建产物位于 =cpp/build/<chapter>/<example>/=。
- Python: 大多数示例直接运行 =python path/to/main.py= 即可。
- Basilisp: QML/Quick 示例建议从仓库根目录运行，因为它们按仓库相对路径读取 =Main.qml=。
- Clojure: 直接运行 =clj -M:<alias>=；不要手动拼接 =src/= 下的命名空间文件路径。

** Troubleshooting

*** Python / Basilisp / Clojure 提示找不到 =PySide6=

先确认当前解释器确实装了依赖:

#+begin_src bash
python -c "import PySide6; print(PySide6.__version__)"
#+end_src

如果失败，说明你当前 shell 使用的不是装好依赖的解释器。优先做法是激活 venv，然后再运行示例或 =clj=。

*** 没有 =conda=

文档中的 =conda= 只是可选路径，不是前置条件。仓库默认支持标准 =venv= + =pip= 工作流。

*** CMake 找不到 Qt6

- 确认安装的是 Qt 6 而不是 Qt 5。
- 用 =-DCMAKE_PREFIX_PATH= 指向 Qt 安装根。
- macOS/Homebrew 环境下，必要时显式指定 =Qt6_DIR= 或 =CMAKE_PREFIX_PATH=。

*** QML / Quick 示例在无桌面环境下卡住

部分 QML/Quick 示例支持自动退出，可用于 smoke run:

#+begin_src bash
QT_QPA_PLATFORM=offscreen \
QT6_TUTORIAL_AUTOQUIT=200 \
python python/04_qml/01_basics/main.py
#+end_src

同样的 =QT6_TUTORIAL_AUTOQUIT= 也适用于若干 Basilisp / Clojure QML 与 Quick 示例。

*** 多媒体 / 3D 示例无法构建

这通常不是主线教程的问题，而是本机缺少可选 Qt 模块。先完成 =01_core= 到 =07_sql=，之后再补装:

- Qt Multimedia: =08_multimedia/=
- Qt 3D: =11_3d/=

*** macOS 上 Clojure GUI 失败

=deps.edn= 里的 alias 已经包含 =-XstartOnFirstThread=。如果你绕过 alias 直接跑 JVM，GUI 示例很容易失败。

** 学习建议

1. 先跑 =01_core/01_meta_object=，确认环境正常。
2. 再按 =01_core -> 05_quick -> 06_network -> 12_project= 逐步推进。
3. 每章优先对照 C++ 与 Python，再看 Basilisp 或 Clojure 变体。
4. 遇到可选模块问题时先跳过，不要阻塞主线学习。
