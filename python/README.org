#+TITLE: PySide6 Qt6 教程 - Python 版本

* Python / PySide6 示例

=python/= 目录提供与 Qt6 主线章节对应的 PySide6 实现，适合用更低的环境门槛学习同样的 API 主题。

** 前置要求

- Python 3.9+
- PySide6 6.5+

** 安装

*** 推荐: venv + pip

从仓库根目录执行:

#+begin_src bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r python/requirements.txt
#+end_src

验证安装:

#+begin_src bash
python -c "import PySide6; print(PySide6.__version__)"
#+end_src

*** 可选: conda

如果你本机已经安装了 =conda=，也可以使用:

#+begin_src bash
conda create -n qt6-py python=3.11 -y
conda activate qt6-py
python -m pip install -r python/requirements.txt
#+end_src

** 快速开始

*** 运行第一个示例

#+begin_src bash
source .venv/bin/activate
python python/01_core/01_meta_object/main.py
#+end_src

*** 运行 Widgets 示例

#+begin_src bash
python python/03_widgets/01_basic_widgets/main.py
#+end_src

*** 运行 QML / Quick 示例

#+begin_src bash
python python/04_qml/01_basics/main.py
python python/05_quick/01_items/main.py
#+end_src

** 运行约定

- 绝大多数示例都可以直接执行:

#+begin_src bash
python path/to/main.py
#+end_src

- QML/Quick 示例通过 =__file__= 定位同目录下的 =Main.qml=，因此既可以从仓库根目录运行，也可以先 =cd= 到示例目录再运行。
- 网络、多媒体、测试类示例可能会打开窗口、访问网络或等待用户操作，不适合直接批量跑完。

** Headless / 冒烟运行

若在无桌面环境中验证部分 QML/Quick 示例，可尝试:

#+begin_src bash
QT_QPA_PLATFORM=offscreen \
QT6_TUTORIAL_AUTOQUIT=200 \
python python/04_qml/01_basics/main.py
#+end_src

=QT6_TUTORIAL_AUTOQUIT= 目前只在部分 QML/Quick 示例中实现，不是每个示例都支持。

** Troubleshooting

*** =ModuleNotFoundError: No module named 'PySide6'=

你当前调用的 Python 没装 PySide6。先激活 venv，再重新验证:

#+begin_src bash
source .venv/bin/activate
python -c "import PySide6; print(PySide6.__version__)"
#+end_src

*** 没有 =conda=

不影响使用。本目录默认支持 =venv= + =pip=，不依赖 conda。

*** QML / Quick 启动后不退出

这是正常现象，很多示例会启动 GUI 事件循环。若只想做自动化检查，优先使用支持 =QT6_TUTORIAL_AUTOQUIT= 的示例并配合 =QT_QPA_PLATFORM=。

*** 多媒体或摄像头示例没有输出

先确认本机具备:

- 对应 Qt Multimedia 组件
- 可用音频/视频设备
- 桌面会话权限

*** GUI 测试在 CI 或 SSH 中失败

Qt GUI 相关示例依赖显示服务。必要时使用虚拟显示，或只跑非 GUI / 支持 offscreen 的示例。
